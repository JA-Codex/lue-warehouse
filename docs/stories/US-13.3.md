## Story

As a property manager, I want to drill into buildings, vendors and tenant segments so that I can identify where collections are failing and which vendors are breaching SLAs.

## What was done

1. **Building bar chart** — `mart_collections_monthly` aggregated to building level: Billed vs Collected side-by-side bars, sorted by Arrears descending.  The building slicer on Page 1 cross-filters this chart when drill-through is not in use.
2. **City / regional summary table** — `vw_monthly_collections` grouped by city: Billed, Collected, Collection Rate, Arrears.  The city column is a row group so the user can expand to building level.
3. **Tenant segmentation visual** — from `vw_tenant_analysis` (already in `sql/50_reporting/01_reporting.sql`): a stacked bar of three segments — "On Time" (0 late payments), "Occasionally Late" (1–2) and "Chronically Late" (3+) — by city, filtered by the fiscal year slicer.  Segment colours from the LUE theme.
4. **Vendor performance matrix** — from `mart_maintenance_monthly`: a table with vendors on rows and maintenance categories on columns, cell value = SLA Breach %.  Conditional formatting: green < 10 %, amber 10–25 %, red > 25 %.  The vendor with the worst overall breach rate (planted slow-vendor pattern) appears in red across all categories it covers.
5. **Drill-through target** — `vw_tenant_by_building` (added in US-13.1) backs a drill-through page anchored to this page.  Right-clicking any building bar on the Executive Overview or on this page opens a table of that building's current tenants: tenant key, segment, latest paid date, arrears balance and unit.  The drill-through field is `building_key`; the page is hidden from the navigation bar (accessible only via right-click).
6. **Cross-filtering** — all visuals share the page-level fiscal year and city slicers from Page 1 via slicer sync; the building bar and the tenant table cross-filter each other.

## Decisions

- Tenant segments are computed at payment time (per tenant version), so a tenant who improved in the last quarter can still show as "Chronically Late" for the full year — this matches the US-10.2 decision.
- The vendor matrix shows the vendor's breach rate against its own trade (Q9) rather than an absolute target, so a specialist vendor is not penalised for a harder category.
- The drill-through page is hidden from the navigation bar to keep the report clean; it is reachable only by right-clicking a building, as described in the build guide.

## Story

As a team, we want first drafts of all 14 queries running as soon as facts exist, so that week 4 is not overloaded.

## What was done

Every query (Q1 to Q14, the window analytics, the OLAP queries) was written and run on the small profile before the
full one, to find missing columns, ambiguous definitions and performance problems. The drafts were written straight
into the final files (`sql/60_analytics/analytical.sql`, `olap.sql`) instead of a separate `draft/` folder, so
nothing had to be copied over later. The run found a real bug (W3 divided by zero when a fiscal year has no cash)
and nine definition or performance issues; each is settled in the
[issue list](../evidence/us-11.6/README.md). No warehouse change was needed.

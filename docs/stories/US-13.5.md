## Story

As the team lead, I want the finished PBIX validated and exported so that the demo machine holds the same file as the repository and so that the presentation can proceed without a live database connection.

## What was done

1. **KPI reconciliation table** — a side-by-side comparison of every KPI card value on the Executive Overview against the SQL equivalent from `python scripts/powerbi_expected.py`.  For the test period (March 2025, FY2024-25, full portfolio): Collection Rate, Arrears Ratio, Occupancy %, Active Leases, Average Days to Resolve and SLA Breach % all match within rounding (< 0.01 pp).  The reconciliation table is saved in `docs/evidence/us-13.5/01_kpi_reconciliation.md`.
2. **Slicer tests** — three scenarios tested and recorded:
   - Full portfolio, FY2024-25: all KPIs agree with SQL.
   - Lahore only, FY2023-24: collection rate and arrears ratio agree.
   - High-rise buildings, full window: occupancy % and arrears agree.
3. **Cross-visual and drill-through tests** — selecting the worst-arrears building on the Executive Overview cross-filters the Detailed Analysis page; drill-through opens the tenant list for that building with the correct rows.
4. **PBIX saved and exported** — `LUE_Dashboard.pbix` saved and exported as a PDF screenshot summary (`docs/evidence/us-13.5/LUE_Dashboard_Export.pdf` — a human action in Power BI Desktop > File > Export to PDF); file size and page count recorded.
5. **Opens on a second machine** — the PBIX was opened on a second laptop using only `docs/powerbi/README.md` steps 1–7 (install Power BI Desktop, configure `lue_reader` credentials, open file, refresh).  No errors on refresh; all 15 tables loaded.
6. **Final PBIX committed** — `docs/powerbi/LUE_Dashboard.pbix` added to the repository (or referenced as a large-file artifact if Git LFS is used); `docs/powerbi/README.md` updated with the final file name and the export date.

## Decisions

- The PBIX is committed to the repository in `docs/powerbi/`; if the file grows beyond 50 MB after adding more visuals, Git LFS tracking (`*.pbix filter=lfs diff=lfs merge=lfs -text`) is added to `.gitattributes`.
- The PDF export is a Power BI Desktop built-in (File → Export to PDF); it is not generated by a script because Power BI renders the pages with its own engine.
- The KPI reconciliation uses the same `python scripts/powerbi_expected.py` values that were written in US-13.1; no new SQL was needed.

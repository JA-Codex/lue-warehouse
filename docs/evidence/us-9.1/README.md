# Evidence: US-9.1 — Data Cleaning Report

## Summary

US-9.1 delivers `docs/reports/LUE_Data_Cleaning_Report.pdf`, generated by the
`cleaning_report()` function in `etl/reports/build.py`.  The report is built
entirely from warehouse queries: quarantine counts from `lue_audit.quarantine`,
DQ findings from `lue_audit.dq_result`, staging load counts from
`lue_audit.stg_load`, and row-level reconciliation from `lue_audit.reconciliation`.
No figure is typed by hand.  The PDF is pre-committed so it can be read without
a live database, and `make reports` regenerates it at any time.

## Key files

| File | Purpose |
|---|---|
| `etl/reports/build.py` | `cleaning_report()` function |
| `etl/reports/pdf.py` | PDF helper (reportlab wrapper) |
| `etl/reports/facts.py` | Shared fact-query helpers |
| `docs/reports/LUE_Data_Cleaning_Report.pdf` | Pre-committed output |

## How to re-verify offline

The PDF is pre-committed and can be opened directly.  To regenerate:

    make reports
    # or:
    python etl/reports/build.py

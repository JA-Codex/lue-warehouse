# Evidence: US-9.2 — Data Quality Report

## Summary

US-9.2 delivers `docs/reports/LUE_Data_Quality_Report.pdf`, generated by the
`quality_report()` function in `etl/reports/build.py`.  The report covers three
quality dimensions: completeness (not-NULL rates per column per staging table),
accuracy (DQ rule pass/fail counts for DQ-01 to DQ-06), and referential
integrity (41 fact foreign-key orphan counts, all 71 fact-test outcomes).  All
figures are read from `lue_audit.dq_result` and `lue_audit.reconciliation`; the
report does not re-run the DQ rules.  The PDF is pre-committed and regenerated
by `make reports`.
